# ABDULBASIT SPACE 🚀

> **پلاتفۆرمی مۆبایلی یەکگرتوو، زۆر پێشکەوتوو بە زمانی کوردیی سۆرانی بۆ دەستکاریکردنی وێنە و ڤیدیۆ، زیرەکی دەستکرد (AI)، دروستکردنی ئەپ و وێبسایت، توێژینەوە و بەڕێوەبردنی فایلەکان.**

---

## 🌟 تایبەتمەندییە سەرەکییەکان

### ١. گفتوگۆی زیرەکی دەستکرد (AI Chat)
- یاریدەدەری کوردیی زیرەک بە مۆدێلی نوێی **Gemini** بۆ نووسین، کۆد، بیرۆکەی وێنە و سناریۆی ڤیدیۆ.
- پاشەکەوتکردنی هەموو مێژووی چاتەکان لە بنکەدراوەی خۆماڵی **Room** و توانای کۆپیکردنی وەڵامەکان.
- توانای کارکردنی ئۆفڵاین کاتێک ئینتەرنێت دەپچڕێت لەگەڵ ڕێنمایی تەواو.

### ٢. دەستکاریکردنی پێشکەوتووی وێنە (Image Studio - Picsart)
- هێنانەناوەوەی وێنە لە گەلەری مۆبایل (`PickVisualMedia`).
- سلایدەری ڕێکخستنی ڕووناکی، کۆنتراست و تێری ڕەنگ (Saturation).
- ٨ فلتەری هونەری مۆدێرن (ڕەش و سپی، سێپیا، سایبەرپەنک، گەرم، سارد، هیتر).
- زیادکردنی دەقی کوردی بە قەبارە و ڕەنگی دڵخواز لەسەر وێنەکە.
- سووڕاندنی ٩٠ پلە بۆ چەپ و ڕاست، پێچەوانەکردنەوە، و سیستەمی مێژوو (Undo / Redo).

### ٣. دروستکردنی وێنە بە AI (AI Image Studio)
- گۆڕینی بیرۆکەی کوردی بۆ پڕۆمۆپتی دەوڵەمەند و پرۆفیشناڵ بۆ مۆدێلە بەرزەکانی دروستکردنی وێنە.
- هەڵبژاردنی ستایلەکان (Realistic 4K، Cyberpunk، 3D Animation، Anime Studio، Watercolor، Logo).
- دیاریکردنی ڕەهەندی شاشە (1:1، 9:16، 16:9، 4:3).

### ٤. دەستکاریکردنی ڤیدیۆ (Video Editor - CapCut)
- هێڵی کاتی فرە-چین (**Multi-Track Timeline**) بۆ ڤیدیۆ، ژێرنووس و مۆسیقا.
- بڕین و ڕێکخستنی سەرەتا و کۆتایی کلیپ بە سلایدەر (Trim & Split).
- گۆڕینی خێرایی پەخش (0.5x هێواش، 1.0x ئاسایی، 1.5x، 2.0x خێرا).
- گۆڕینی ڕەهەند (9:16 بۆ تیکتۆک و ڕیڵز، 16:9 بۆ یوتیوب، 1:1 بۆ ئینستاگرام).
- زیادکردنی ژێرنووس و سەردێڕی کوردی و دەنگی پاشبنەما.

### ٥. دروستکردنی ڤیدیۆ بە AI (AI Video Studio - Veo)
- داڕشتنی سناریۆی تەواوی ڤیدیۆ لە دەقێکی کوردی.
- دابەشکردنی دیمەنەکان (Scene breakdown)، کاتی هەر دیمەنێک، جوڵەی کامێرا (Drone، Pan، Zoom) و پڕۆمۆپتی ئینگلیزی بۆ مۆدێلی Veo.

### ٦. دروستکردنی ئەپی ئەندرۆید بە AI (Android App Builder)
- داڕشتنی تەلارسازی و کۆدی Kotlin و Jetpack Compose بە پێی پڕۆمۆپت.
- پێشبینینی کارلێککەری ناوخۆیی (**Interactive Sandbox Preview**).
- پشکنەری فایلەکانی پڕۆژە و ڕێنمایی بیلد بۆ فایلی APK.

### ٧. دروستکردنی وێبسایت بە AI (Website Builder)
- دروستکردنی کۆدی HTML5، CSS3 و JavaScript لە ڕێگەی پڕۆمۆپت بە ئاراستەی RTL.
- بینینی ڕاستەوخۆ بە **WebView** لەناو ئەپدا لەگەڵ گۆڕینی پیشاندان بۆ مۆبایل و شاشەی گەورە.

### ٨. توێژینەوە و شیکردنەوەی فایل (Deep Analysis & EXIF)
- پشکنینی زانیاری تەکنیکی فایل و EXIF (قەبارە، فۆرمات، بیرگە و تایبەتمەندی).
- دەرهێنانی پالێتی ڕەنگە سەرەکییەکان (Dominant Palette) بە کۆدی HEX و کۆپیکردنی ئاسان.
- شیکردنەوەی قووڵی ناوەڕۆک بە AI Vision.

### ٩. دروستکردنی فایلی PDF (PDF Studio)
- دروستکردنی فایلی فەرمی PDF بە تەواوی ئۆفڵاین لە ڕێگەی بزوێنەری خۆماڵی Android `PdfDocument`.
- گۆڕینی دەق، وێنە و ڕاپۆرتەکان بۆ بەڵگەنامەی A4 بە ستایلی کوردیی RTL و هاوبەشکردنی.

### ١٠. بەڕێوەبردنی کلیلەکانی AI (API Key Manager)
- تۆمارکردنی پارێزراوی کلیلی Gemini لەناو مۆبایل بەبێ دزەپێکردن.
- هەڵبژاردنی مۆدێلی بنەڕەتی و ئەنجامدانی تاقیکردنەوەی خێرایی و پەیوەندی (Latency Ping Test).

### ١١. پڕۆژەکانم (Project & File Manager)
- خەزنکردنی هەموو وێنە، ڤیدیۆ، ئەپ، ماڵپەڕ و بەڵگەنامەکان لە بنکەدراوەی **Room**.
- فلتەرکردن بە پێی پۆلێن و گەڕانی خێرا بە ناونیشان و ناوەڕۆک.

### ١٢. ڕێکخستنەکان (Settings)
- گۆڕینی دۆخی تاریک (Dark Mode) و ڕوون.
- بەڕێوەبردنی بیرگە و پاککردنەوەی کاش (Clear Cache).
- پیشاندانی دۆخی پەیوەندی بە تۆڕ (Online / Offline Diagnostics).

## 🛠 پێداویستییە تەکنیکییەکان
- **زمان**: Kotlin
- **ڕووکار**: Jetpack Compose (Material Design 3)
- **بنکەدراوە**: Room Database (Local Persistence)
- **تۆڕ**: OkHttp 3 & Retrofit (Timeout 60s بۆ مۆدێلەکان)
- **ئاراستەی نووسین**: Native RTL Layout Direction (کوردی سۆرانی)
- **کۆنتڕۆڵی دۆخ**: StateFlow & Kotlin Coroutines
- **پشکنینی تۆڕ**: Android ConnectivityManager NetworkCallback

## 📱 چۆنیەتی دروستکردن و داگرتنی APK لە ڕێگەی GitHub Actions

ئەم پڕۆژەیە لەگەڵ فایلی ئۆتۆماتیکی `.github/workflows/android-build.yml` ئامادەکراوە:

١. کاتێک کۆد بۆ برانچی `main` ڕەوانە (push) دەکرێت، GitHub Actions خۆکارانە دەست بە کار دەبێت.
٢. دەتوانیت بە دەستی لە تابەی **Actions** لە GitHub دوگمەی **Run workflow** دابگریت.
٣. پاش تەواوبوونی بیلد، لە بەشی خوارەوەی پەیجی ئەکشن لە ژێر ناوی **Artifacts** فایلی **`ABDULBASIT-SPACE-Debug-APK`** ئامادە دەبێت.
٤. لە مۆبایلەکەت کلیکی لێ بکە بۆ داگرتن و بە ئاسانی دایمەزرێنە!
